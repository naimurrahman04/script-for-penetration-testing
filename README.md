# Penetration Testing Scripts

Collection of penetration testing utility scripts: header checks, SSH banner grabbing, MongoDB checks, CSP analysis, network segmentation, and more.

## Installation

```bash
git clone https://github.com/naimurrahman04/script-for-penetration-testing.git
cd script-for-penetration-testing
pip install -r requirements.txt
```

## Usage

```bash
python <script>.py  # see individual scripts
```

> **Note:** Some scripts are Windows-specific (win32process). Review each before use.

## ⚠️ Legal & Ethical Use

For authorized security testing only. Only test systems you own or have explicit written permission to assess.
